# Mazaj+ 1500-Food Offline Nutrition Dataset

هذه الحزمة هي النسخة الموسعة من داتا Mazaj+، وتحتوي على **1500 أكلة** للعمل من قاعدة البيانات الداخلية بدون أي Nutrition API أثناء تشغيل الموقع.

## ملخص التوسيع

- تم الحفاظ على جميع أطعمة Mazaj+ الحالية: **232** أكلة.
- تمت إضافة **1268** أكلة من ملف USDA FoodData Central — FNDDS 2021–2023.
- العدد النهائي داخل `foods.csv`: **1500** أكلة.
- تمت تغطية **156** فئة WWEIA غذائية من FNDDS، تشمل الألبان، اللحوم، الدواجن، الأسماك، الحبوب، الخضروات، الفواكه، المشروبات، الوجبات المركبة، السناكس، الحلويات، الصلصات، والدهون.

## قاعدة القياس

- جميع قيم السعرات والماكروز والعناصر الغذائية داخل `foods.csv` محسوبة لكل **100 جرام** من الجزء القابل للأكل.
- `food_nutrition_basis.csv` يوثق قاعدة القياس لكل `food_key`.
- `food_portions.csv` يحتوي على حصة مرجعية ثابتة مقدارها 100 جرام لكل طعام.
- تحليل الصور لا يجب أن يقدّر وزن الحصة أو إجمالي سعرات الطبق تلقائيًا.

## مصادر الداتا

- أطعمة Mazaj+ القديمة تم الحفاظ عليها كما هي، لأن الملفات الأصلية لم تحتفظ بمعرّف المصدر لكل صف.
- الأطعمة الجديدة مستوردة من USDA FoodData Central — FNDDS 2021–2023.
- تم حفظ `FDC ID` لكل أكلة جديدة داخل `food_sources.csv`.
- تفاصيل المصدر موجودة داخل `data_sources.csv`.

## حدود الاستخدام الآمن

الأطعمة الجديدة من USDA مسموح استخدامها في:
- البحث عن الطعام بالاسم
- مطابقة نتائج التعرف على الصور
- عرض القيم الغذائية لكل 100 جرام
- تسجيل الاستهلاك اليومي

الأطعمة الجديدة **غير مسموح** استخدامها تلقائيًا في:
- توصيات المزاج
- خطط التغذية
- قرارات الحساسية
- قرارات الحالات الصحية
- البدائل الصحية

السبب: بيانات USDA توفر القيم الغذائية، لكنها لا توفر قواعد Mazaj+ الخاصة بالمزاج والحساسية والحالات الصحية. لذلك تم وضع الأطعمة الجديدة في `food_usage_policy.csv` بالحالة:

`USDA_FNDDS_LOOKUP_TRACKING_ONLY`

ولا يجب تفعيلها داخل التوصيات أو الخطط قبل مراجعة قواعد السلامة الخاصة بها.

## الاستبعادات

للحفاظ على ملاءمة الداتا لفكرة Mazaj+ الموجهة للبالغين، لم يتم استيراد:
- المشروبات الكحولية
- أغذية الأطفال والـ formula وhuman milk
- الأطعمة غير المصنفة
- الأسماء غير المحددة مثل NFS وNS as to وNot specified

## قواعد Mazaj+ التي يجب الحفاظ عليها

- قاعدة بيانات Mazaj+ الداخلية هي المصدر الوحيد للقيم والقرارات الغذائية أثناء التشغيل.
- Gemini Vision يعرّف اسم الطعام فقط.
- Gemini أو أي AI لا يحسب السعرات ولا يغير القيم الغذائية.
- يجب البحث عبر `FoodAlias` ثم `FoodItem`.
- عند عدم وجود مطابقة، يجب إرجاع رسالة عدم توفر الداتا بدل اختيار طعام قريب أو عشوائي.
- يجب احترام `food_usage_policy.csv` قبل استخدام أي طعام في توصية أو خطة.
