# Mazaj+ Data Notes

- Current nutrition data is demo seed data only.
- The final curated nutrition dataset will be provided later by the project team.
- Gemini does not create nutrition data, calories, macros, meal plans, safety decisions, or health rules.
- The Mazaj+ backend database and rule layer remain the source of nutrition decisions.
- Frontend features must not invent nutrition values, body composition values, recommendations, or safety results.
- Food image recognition, when available, may identify a food label through the backend only; nutrition values must still come from the Mazaj+ database.
- InBody upload v1 does not perform automated parsing or diagnosis.
